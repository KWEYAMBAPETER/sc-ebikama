# SC Ebikama Website

A modern, responsive, single-page website for **SC Ebikama** — a community-driven sports club. The site features a clean design with a bold green and gold color scheme, a dynamic fixtures section, an interactive gallery, and a working contact form powered by Formspree.

**Tagline:** *Strength. Unity. Community.*

## 🚀 Getting Started

### Option 1: Open Directly (Not Recommended)
You *can* double-click `index.html` to open it in your browser, but **the contact form will not work** because of browser security rules (CORS). The browser blocks external API requests from `file://` URLs.

### Option 2: Use a Local Server (Recommended)
To test the contact form locally, you need to serve the site through a local server:

**Using VS Code (Easiest):**
1. Install the **Live Server** extension in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.
3. Your browser will open `http://127.0.0.1:5500/index.html`.
